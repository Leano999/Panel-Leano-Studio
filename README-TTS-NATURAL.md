# TTS IndoFinity Natural

TTS menggunakan Microsoft Edge online neural TTS tanpa Azure API key.

- Voice tetap: `id-ID-GadisNeural`
- Tidak ada pilihan voice di panel.
- Rate/pitch/volume tetap dapat diatur.
- Saat pertama kali menjalankan panel, `npm install` akan memasang `node-edge-tts`.
- Dibutuhkan koneksi internet saat membuat audio TTS.

Catatan: suara dibuat agar natural dan mendekati karakter contoh IndoFinity, tetapi tidak mengkloning suara proprietary secara persis.
