PANEL SIAR - CARA MENJALANKAN — v23

1. Pastikan Node.js LTS sudah terinstall di Windows.
2. Untuk pertama kali saja, klik dua kali:
   START PANEL.bat
3. Script akan otomatis:
   - mengecek Node.js/npm
   - menjalankan npm install jika dependency belum ada
   - menjalankan server
   - membuka Control Panel di browser
4. Setelah itu setiap kali mau mulai live, cukup klik START PANEL.bat.

TIDAK PERLU mengetik:
  npm install
  npm start

Folder ini harus tetap utuh. Jangan hapus folder node_modules setelah instalasi pertama.

Untuk menghentikan server: kembali ke jendela hitam START PANEL.bat lalu tekan Ctrl+C.
