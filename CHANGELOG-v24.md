# v24 — Music Request Only

- Music Player is strictly request-only.
- No YouTube playback starts when there is no `!song` request.
- Activating the Music Browser Source only unlocks audio; it does not play anything by itself.
- When the current request ends and the queue is empty, playback stops and the overlay hides.
- Browser Source refresh does not resume or start a previous/empty player.
- Existing v23 Music Request features remain unchanged.
