# Panel Siar v4 — overlay & TTS stability

- Chat comments no longer disappear after a few seconds.
- Latest 40 comments are kept by the server and replayed after overlay refresh.
- Comment feed is scrollable and keeps its own bottom area.
- Goal widget moved to the top so it does not collide with the chat feed.
- TTS changed to a queued speech engine with voice refresh, resume, retry and stuck-utterance recovery.
- Added “Aktifkan Mesin Suara” and “Tes Suara Terpilih” controls.
- Browser/OBS autoplay limitations are surfaced instead of silently failing.
